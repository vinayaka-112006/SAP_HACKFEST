# Connected synthetic fixture graph

`backend/db/seed/v21.js` prepares 106 namespaced records:

| Data | Rows |
|---|---:|
| Additional tools | 5 |
| Mandatory equipment policies | 5 |
| Work stations | 5 |
| Production demand orders | 5 |
| Illustrative knowledge documents | 5 |
| Compatible spare parts | 20 |
| Profiles: 14 workers, 8 technicians, 4 management roles | 26 |
| Workforce qualification/shift profiles | 14 |
| Technician qualifications | 8 |
| Multilingual/current/repeat/historical incidents | 10 |
| Active and historical repair logs | 2 |
| Accepted repair work order | 1 |

Identifiers use `V21-`. Names, certifications, demand rates and documents are
synthetic and labeled accordingly; no real identity-provider accounts or passwords
are created. Seed rows are compared before any insertion. Identical rows are skipped;
differing identifiers abort the transaction. The fixture's dated shift boundary
eventually expires rather than silently extending worker availability.

No original Tool B uses, production runs, batches, units, stocks or shipments are
changed. Three workers are associated with failed V21-TOOL-1; two qualify for
alternative motor/inspection demand and one is excluded. Stock examples include
available and out-of-stock parts. Historical repair and an accepted active work
order are linked to actual fixture incidents/equipment.

After explicit user approval and verified recoverable backup, all 106 fixture rows
were inserted into HANA, together with one seed audit entry. All 585 original rows
were preserved; the repeat preview proposes zero inserts. The SQLite demo launcher
creates a separate local database. Neither HANA launcher auto-seeds the database.
