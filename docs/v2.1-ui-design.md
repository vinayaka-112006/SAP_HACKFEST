# Enterprise UI changes

The existing logo, components, routes, trace views and approval forms remain.
`enterprise.css` supplies a navy industrial shell, cyan/teal accents, frosted
readable data surfaces, shared focus states, rounded controls and restrained motion.
The original role buttons move into a clearly labeled collapsible demo panel;
language and workspace navigation remain immediately accessible.

The robotic assistant launcher opens a bounded glass dialog with separate message
bubbles, avatars, citation cards, history, keyboard submission, Escape/close,
recording input where authorized, explicit provider errors and a scrolling message
region. Requests/history reset on identity, incident or language context change.
Viewport-relative height and mobile layout keep the panel inside the visible page.

The voice panel shows state, waveform, transcript correction, conversation history,
audio playback, push-to-talk, manual fallback and editable confirmation. Recording
is excluded while the assistant speaks. Workforce cards show numeric benefit and
its stored assumptions rather than decorative fabricated metrics.

The evidence console adds a selectable investigation timeline for existing verified-good,
report, snapshot, batch and gap records. Missing times remain missing; shipment
evidence is not described as live product location. Existing location/tier/evidence
views remain the source for detailed trace decisions.

Reduced-motion CSS disables added animations. Browser layout checks passed at
375/768/1280/1440 pixels. Full accessibility certification and physical on-screen
keyboard testing are not claimed.
