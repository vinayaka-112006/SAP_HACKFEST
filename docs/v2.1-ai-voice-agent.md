# AI voice agent and diagnosis

The implementation uses Sarvam STT → Groq reasoning → Sarvam TTS. A worker first
selects registered equipment and language; the Voice Agent control starts an
owner-bound conversation and reads its first question. Reviewed transcripts and
typed answers use the same versioned message route with `reason: true`.

Groq extracts observations supported by exact worker-text quotations, respects
explicit corrections, and proposes a missing-field follow-up. Invalid/unavailable
output retains typed facts and the selected-language fallback question. Catalogue
codes map deterministically to their supplied category; unsupported suggestions
are discarded. Missing measurements and event times are never invented.

The interface exposes IDLE, SPEAKING, LISTENING, TRANSCRIBING, REASONING, REVIEW and
CONFIRMED. Push-to-talk capture is disabled during speech/reasoning. Audio tracks
and requests are cancelled on context change; the transcript can be corrected.
Confirmation remains an explicit final action. Assistant questions are excluded
from persisted original worker text. Raw audio is not stored.

## Verified root causes and evidence

- `TS-00078` is absent from HANA and the current SQLite file and is not hardcoded
  in source. Saved session selection can outlive its originating database.
  Database fingerprints and actionable not-found recovery now address that case.
  No replacement record is inserted.
- The prior reasoning routes selected Sarvam even though Groq credentials existed.
  They now use the provider interface with active Groq model discovery and validated
  JSON, preserving Sarvam speech. Historical STT 503 was not reproduced with the
  current credentials; successful real checks do not establish its past cause.
- WebM is officially supported by the Sarvam endpoint. MediaRecorder bytes keep
  their actual MIME type; no false WAV labeling or unnecessary conversion was added.
- React Router's installed v6 supports the enabled v7 future flags. Browser checks
  account for navigation transitions; no major router upgrade was made.

Real English two-turn HTTP conversation, structuring, TTS/STT and confirmation
passed using isolated SQLite. English/Hindi/Kannada synthetic TTS/STT round-trips
passed. A physical worker microphone and noisy plant recordings remain untested.
See `v2.1-live-flow.json` and `v2.1-provider-checks.json`.
