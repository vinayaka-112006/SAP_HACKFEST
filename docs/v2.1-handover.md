   main merge. Backend: `fb69354`; frontend/launcher: `4c44c0e`. The documentation
   commit follows these; final chat records its ID. Working tree is clean at handoff.
2. **Incident 404:** TS-00078 is absent in both current HANA and SQLite and is not
   hardcoded. Instance-bound restored selection and actionable not-found state
   prevent silently treating a missing report as a new incident.

   outage could not be reproduced. Reasoning used Sarvam despite a Groq key;

   voice UI, static legacy localization, workforce recommendations/approval,

   endpoints also passed in English. Physical microphone and plant-noise tests
   remain unverified.

   calls passed. No success was fabricated from a mock response.
